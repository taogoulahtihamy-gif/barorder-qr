Add real sound notifications for BarOrder admin.

Goal:
When a new order or server call arrives, the correct admin role receives a visible notification + sound.

Do not break existing features.

1. Notification targets
- kitchen: sound when new order is created
- waiter: sound when server call is created or order becomes ready
- cashier: sound when order becomes served or payment is pending
- admin/super_admin/manager: sound for all important events

2. Frontend
Create a notification service:
- request browser notification permission
- play a short notification sound
- show toast notification
- update bell badge count

3. Sound
Use Web Audio API or a small local sound file.
Must work on desktop and mobile after first user interaction.
If autoplay is blocked, show button:
“Activer les notifications”
Once clicked, sounds are enabled.

4. Socket/realtime
Use existing socket if available.
If socket fails, fallback to polling every 5 seconds.

Listen for:
- new_order
- order_status_updated
- server_call_created
- payment_updated

5. UI
Add notification bell dropdown in admin header:
- unread count
- latest 10 notifications
- mark all as read

6. Role filtering
Do not notify roles for events they should not see.

7. Build and push.

Acceptance:
- creating order from QR triggers sound on kitchen/admin
- calling server triggers sound on waiter/admin
- marking order ready triggers sound on waiter
- bell badge increases
- toast appears
- no console crash
