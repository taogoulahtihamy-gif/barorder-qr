URGENT FIX: ReferenceError t is not defined after i18n refactor.

Problem:
Admin pages become black.
Console shows:
ReferenceError: t is not defined

Cause:
Some components use t("...") but do not import or initialize the translation hook.

Fix:

1. Search all client/src for:
t(
tStatus(
tPaymentMethod(
tRole(
tAction(

2. For every component using t, add:
import { useT } from "../i18n/useT";
or correct relative path.

Inside component:
const { t, tStatus, tPaymentMethod, tRole, tAction } = useT();

3. If component is outside normal path, fix import path correctly.

4. Do not use global variable t.
5. Do not leave any t(...) call without useT().
6. Do not break existing translations.

7. Add safety:
If t is missing, component must not crash.
But preferred fix is proper useT import.

8. Run:
npm run build

9. Commit and push:
git add .
git commit -m "Fix missing i18n hook references"
git push origin main

Acceptance:
- no ReferenceError: t is not defined
- /admin/orders opens normally
- /admin/role-test opens or is hidden properly
- /admin/kitchen opens normally
- language switch still works
