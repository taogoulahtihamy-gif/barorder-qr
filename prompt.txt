Implement persistent active order tracking button for customers.

Goal:
Allow customer to return to their current order tracking page from anywhere in the client app.

Do NOT break:
- QR flow
- cart
- checkout
- realtime notifications
- restaurant routing
- multilingual system

==================================================
1. ACTIVE ORDER STORAGE
==================================================

When an order is successfully created:

Save in localStorage:
- activeOrderId
- activeRestaurantSlug
- activeTableId
- activeOrderNumber
- activeOrderStatus

Example:
{
  id,
  order_number,
  restaurant_slug,
  table_id,
  status
}

==================================================
2. GLOBAL ACTIVE ORDER BUTTON
==================================================

Create floating persistent button component:

client/src/components/customer/ActiveOrderButton.jsx

Behavior:
- visible on all customer pages
- only visible if active order exists
- hidden if order status:
  - paid
  - cancelled
  - completed

Position:
- bottom right mobile
- bottom right desktop

Style:
- premium floating pill
- dark glassmorphism
- gold/emerald accent
- animated pulse when order updates

Content:
FR:
- Suivre ma commande

EN:
- Track my order

Show:
- order number
- current status badge

==================================================
3. BUTTON ACTION
==================================================

On click:
navigate to:
- /orders/:orderId

OR existing tracking route.

==================================================
4. AUTO CLEANUP
==================================================

If order becomes:
- paid
- cancelled
- completed

Then:
- remove active order from localStorage
- hide floating button

==================================================
5. REALTIME SYNC
==================================================

When socket receives order status update:
- update localStorage activeOrderStatus
- update floating button badge in realtime
- animate button softly

==================================================
6. CUSTOMER EXPERIENCE
==================================================

Customer flow:

1. Scan QR
2. Add cart
3. Checkout
4. Leave tracking page
5. Browse menu or another page
6. Floating button still visible
7. Tap button
8. Return instantly to tracking page

==================================================
7. OPTIONAL MINI PANEL
==================================================

On hover/click:
show mini popup:
- Order number
- Current status
- Total amount
- Estimated time

==================================================
8. STATUS COLORS
==================================================

Nouvelle:
- gray

Acceptée:
- blue

Préparation:
- orange

Prête:
- emerald

Servie:
- green

Payée:
- gold

Annulée:
- red

==================================================
9. MOBILE SAFE AREA
==================================================

Must not overlap:
- bottom navbar
- iPhone safe area
- browser navigation bar

Use:
padding-bottom env(safe-area-inset-bottom)
