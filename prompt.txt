Refactor BarOrder bilingual system radically and completely.

Problem:
Only some titles change language. Many old texts remain hardcoded in French/English.

Goal:
When language = EN, absolutely every visible text must be English.
When language = FR, absolutely every visible text must be French.
No mixed language anywhere.

Method:
1. Create one central translation system:
client/src/i18n/translations.js
client/src/i18n/I18nProvider.jsx
client/src/i18n/useT.js

2. Translation hook:
const { t, lang, setLang } = useT()

3. Every visible string must use t("key").
Forbidden:
- hardcoded button labels
- hardcoded titles
- hardcoded toasts
- hardcoded placeholders
- hardcoded status labels
- hardcoded modal text
- hardcoded sidebar labels
- hardcoded empty states

4. Search entire client/src for visible strings and replace all of them:
- Dashboard
- Orders
- Kitchen
- Server calls
- Products
- Categories
- Tables
- Payments
- Promotions
- Users
- Role test
- Settings
- Client welcome
- Menu
- Cart
- Checkout
- Order tracking
- Toasts
- Modals
- Errors
- Print labels
- QR labels

5. Add complete dictionaries:
fr: { ... }
en: { ... }

6. Add helpers:
tStatus(status)
tPaymentMethod(method)
tRole(role)
tAction(action)

Examples:
pending:
FR = Nouvelle
EN = New

preparing:
FR = En préparation
EN = Preparing

ready:
FR = Prête
EN = Ready

paid:
FR = Payée
EN = Paid

cash:
FR = Espèces
EN = Cash

wave:
FR = Wave
EN = Wave

orange_money:
FR = Orange Money
EN = Orange Money

admin:
FR = Administrateur
EN = Administrator

manager:
FR = Manager
EN = Manager

7. Language switch:
- must update instantly without page refresh
- must persist in localStorage
- must affect admin and client pages
- same language state everywhere

8. Missing translation protection:
If key is missing:
- console.warn missing key
- show English fallback
- never show undefined
- never show raw key in production UI

9. Add audit script:
Create:
client/scripts/i18n-audit.js

It must scan client/src and report hardcoded visible French/English strings in JSX:
- text between tags
- placeholder
- title
- aria-label
- toast messages
- button labels

Add npm script:
"i18n:audit": "node scripts/i18n-audit.js"

10. Acceptance:
Run:
npm run i18n:audit
npm run build

The audit must show no critical hardcoded UI strings.

Manual test:
- switch to EN: no French text visible anywhere
- switch to FR: no English text visible anywhere
- test especially kitchen, orders, users, checkout, menu, modals, toasts

11. Commit and push:
git add .
git commit -m "Refactor complete bilingual translation system"
git push origin main
