Fix the mobile dashboard order cards layout in BarOrder QR.

Problem seen on /admin/dashboard mobile:
- In "Dernières commandes", status badges like "Nouvelle", "Acceptée", "en attente", "en préparation" overflow outside their card/row.
- Amounts on the right show only numbers like "1250", "1825", "13" without currency.
- Dates are too long and push layout.
- Card content is cramped on iPhone/Safari.

Required fixes:
1. On mobile, each latest-order card must use a clean vertical layout:
   - top row: order number + status badge
   - second row: table + products
   - third row: date/time
   - bottom row: total amount aligned right

2. Status badges:
   - must never overflow outside card
   - use max-width: 100%
   - white-space: nowrap
   - flex: 0 0 auto
   - font-size: clamp(12px, 3.2vw, 14px)
   - padding: 6px 12px
   - border-radius: 999px

3. Amounts:
   - always display with currency:
     "1 250 FCFA", "1 825 FCFA", "13 FCFA"
   - use existing formatCurrency helper if available
   - if not, create a safe formatter:
     new Intl.NumberFormat("fr-FR").format(amount) + " FCFA"

4. Dates:
   - format readable date instead of ISO:
     "16/05/2026 22:06"
   - never display raw ISO string in dashboard cards.

5. Card layout:
   - use flex-wrap: wrap
   - min-width: 0 on all flex children
   - long order numbers can wrap or truncate with ellipsis
   - products line must wrap naturally
   - no horizontal overflow
   - card padding must fit mobile.

6. Apply this specifically to:
   - DashboardPage latest orders section
   - any reusable OrderCard used there

7. Keep current dark premium UI.
8. Do not change backend/API.
9. Run npm run build and fix all errors.

Acceptance test:
On iPhone width 390px:
- no status badge exits card
- every amount has FCFA
- date is readable, not raw ISO
- no horizontal scroll
- cards remain clean and aligned.
